# MovieRecLab V15.1 — 한국어 줄거리 조회 범위 수정 (2026-11-13)

## 문제 원인

V15는 TMDb의 `ko-KR` 줄거리 자체를 조회하지 않았다. 정확한 영화 ID와 연결되는 한국어 위키백과 문서에 `줄거리` 등 명시적 섹션이 존재하는 극히 일부 영화만 한국어로 표시했고, 나머지는 기존 Cinemeta의 영어 원문을 노출했다. V15 테스트에서 위키백과 줄거리 확보에 성공한 2편을 과대 일반화한 게 잘못된 검증이었다.

## 수정된 조회 순서

1. 사용자가 **영화 상세를 직접 열었을 때만**, 기존 MovieLens의 IMDb ID로 `https://tmdb.elfhosted.com/ko-KR/meta/movie/tt{imdb}.json`의 한국어 메타데이터를 요청한다. 반환된 `meta.id`가 정확히 `tmdb:{기존 MovieLens TMDb ID}`와 같고, `description`에 충분한 실제 한국어 텍스트가 있을 때만 채택한다. 영화 ID 불일치, 영문 설명, API 실패, 타임아웃이면 사용하지 않는다. 이 서비스는 **공식 TMDb API가 아닌 ElfHosted 공개 커뮤니티 TMDb 애드온**이다. 별도 인증키가 없어도 실사용 요청에 한국어 응답이 확인되었지만 서비스 운영 정책·이용 제한·가용성이 바뀔 수 있다. 사전 수집이나 일괄 크롤링 없이 개별 영화 열람에 한 번만 호출하고 세션 캐시를 사용한다. 대규모 또는 상업적 운영에는 별도 공식 TMDb API 키와 약관에 맞춘 백엔드가 적절하다.
2. 한국어 메타데이터가 확인되지 않으면 V15처럼 Wikidata `P4947`을 **값까지 대조**한 후 한국어 위키백과 문서의 실제 `줄거리/시놉시스` 섹션을 찾아 표시한다. 위키백과 텍스트는 출처 링크와 `CC BY-SA`를 표시한다.
3. 어느 쪽에도 한국어 줄거리가 없으면 기존 Cinemeta **원문**을 표시한다. 둘 다 없으면 줄거리 부분을 생략한다. 자동 번역이나 조작된 설명은 생성하지 않는다.

한국어 우선 조회 중 Cinemeta 원문을 즉시 노출하면 사용자가 전부 영어라고 오해하기 쉬워, 약 **1.7초 이내**에는 한국어를 먼저 표시할 기회를 준다. 조회가 지연되면 원문을 보여주되 나중에 한국어가 확인되면 교체한다. 두 소스의 출처·라이선스는 서로 구분한다. 한국어 조회에서 부정적 응답이 캐시되면 **3분 뒤 재시도**할 수 있고, 정상 결과는 1시간 캐시한다.

## 공개 한국어 데이터 실험

2026-11-13 GitHub Actions에서 다음 6편을 `tmdb.elfhosted.com/ko-KR`로 요청했으며, 모두 HTTP 200, `Access-Control-Allow-Origin: *`, 해당 TMDb ID와 일치하는 메타데이터 및 한국어 설명이 확인되었다.

- 매트릭스(1999): TMDb 603
- 인셉션(2010): TMDb 27205
- 인터스텔라(2014): TMDb 157336
- 인크레더블(2004): TMDb 9806
- 미녀와 야수(1991): TMDb 10020
- 쇼생크 탈출(1994): TMDb 278

이는 **대표 영화 6편의 성공 사례**이지 MovieLens 9,742편 중 한국어 줄거리 전체 커버리지를 측정한 결과는 아니다. 현재 공개 애드온과 Wikipedia는 가용성과 한국어 데이터가 불완전할 수 있어 전편 한국어를 보장하지 않는다.
