# 평가 방법 민감도 실험 (독립 연구)

기존 V9~V11 결과 및 실제 사이트는 변경하지 않는다. 시간순 평가(A), 과거 이력 무작위 입력(B), 완전 무작위 입력·정답 추출(C)을 비교한다. 신규 가입 시 임의의 과거 영화를 평가하는 행동을 모방하되 B는 미래 평가를 정답으로 유지한다.

- 동일한 사용자·입력 수·후보 조건에서 A 1회, B/C 각 10회. 입력 3/5/10/20/50/100편, 정답 추출 대상은 사용자별 마지막 또는 무작위 20%(최소 3편), 4점 이상만 정답. 입력/정답은 겹치지 않는다. 정답 없는 표본은 지표 0으로 처리하고 비율 별도 기록.
- Small: 기존 44명과 겹치지 않는 고정 88명, 해당 사용자 평점과 태그 제외 후 기존 23개 추천 방식 재학습. 25M: 기존 uid % 509 == 17 대신 29로 독립 사용자 홀드아웃. V10 12개 모델과 기존 V11 가중치 고정 모델 비교; 신규 평가에서 가중치 조정하지 않음.
- 후보: Small 학습 평가 2건 이상, 25M Small과 매칭된 영화 중 학습 긍정 10건 이상. 모델별 자체 후보 제약 유지. 데이터셋 간 절대 점수 직접 비교 금지.
- 사용자 내 반복 평균 후 사용자별 macro NDCG@10, Recall@10, Hit Rate@10 평균·표준편차·사용자 단위 부트스트랩 95% CI(4,000회). Coverage는 반복별 고유 추천 수 평균. A 대비 B/C paired bootstrap CI. 다중 비교 보정 없는 탐색 결과.
- 사전 계산 Tag Genome 정보 누출 가능성, 글로벌 시간 분할 부재, 관측/인기 편향, 작은 표본, 시간순 vs 무작위 정답 난이도 차이 등을 해석에 반영. 기존 평가와 새 표본의 점수 차이는 분할 효과만으로 해석할 수 없음. Small의 다른 역사적 검증 표본과 중복 여부는 확인하지 못함.

실행: GitHub Actions Independent split protocol benchmark 또는 의존성 설치 후 `node tests/split-protocol-benchmark.js 0 1`, `python scripts/benchmark_split_protocols.py`. 결과는 집계 JSON만 워크플로 아티팩트로 저장한다. 원본 데이터, 사용자별 평점/추천 기록, 모델 계수는 공개하지 않는다. 프로덕션 변경 및 자동 채택 없음.
