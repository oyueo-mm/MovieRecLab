# MovieRecLab V15 — 한국어 우선 줄거리와 시네마틱 자동 전환

## 범위

V14 시네마틱 영화 상세 팝업 및 사용자 평가 화면을 유지하면서 (1) 한국어 줄거리 우선/원문 폴백과 (2) 추천 결과 상단의 메인 영화를 **12초마다** 넘기는 **2초 배경 크로스페이드**를 추가한다. V13의 프리셋 8종, 기존 추천 6개 줄, V9~V12 압축 학습 모델, EASE와 User KNN, 평가 기록 방식, 초기 영화 평가 화면의 수동 선택 정책은 변경하지 않는다.

## 줄거리 출처 및 선택

1. **한국어 우선:** 해당 영화의 정확한 TMDb ID로 Wikidata 외부 식별자 **P4947**을 대조한다. 동일 TMDb ID에 연결된 한국어 위키백과 문서가 *유일하게* 확인되면, MediaWiki Action API의 섹션 목록에서 명시적인 `줄거리 / 시놉시스 / 내용 / 이야기 / 스토리` 항목만 가져온다. 짧거나 누락된 섹션은 채택하지 않는다. HTML에서 스크립트·표·출처 주석·편집 링크를 제거하고, 글자만 추출해 최대 약 960자로 제한한다. 이를 한국어 영화 줄거리로 표시한다. 개별 문서 출처 및 **CC BY-SA** 표시를 사용자에게 제공한다.
2. **영문 등 원문:** 정확히 매칭된 한국어 줄거리가 없거나 Wikidata/Wikipedia를 불러오지 못하면 기존 Cinemeta 메타데이터의 `description`을 **원문**으로 표시한다. IMDb/TMDb 외부 링크와 포스터는 V14 동작을 유지한다.
3. **둘 다 부재:** 줄거리 단락 자체를 생략한다. 번역 API를 임의로 사용하거나 줄거리를 생성하지 않는다.
4. **레이스·성능:** 기존 Cinemeta 원문은 도착 즉시 렌더링할 수 있고, 늦게 도착한 한국어 텍스트가 있으면 한국어가 우선한다. 상세 팝업이 닫히거나 다른 영화로 변경된 뒤 도착한 비동기 결과는 무시한다. 한국어 조회 결과·미존재 결과는 브라우저 세션 메모리에서 캐싱하고 동시 호출을 하나로 합친다. 3개 외부 요청에 각각 4.8초 제한을 둔다. 외부 API 장애는 기존 UI 기능을 차단하지 않는다.

**정확한 제약:** TMDb 공식 `ko-KR overview` API는 인증이 필요하다. 이번 V15는 비밀 인증키를 정적 GitHub Pages 웹페이지에 포함하지 않기 위해 공개 Wikidata 및 한국어 위키백과를 통한 영화 ID 일치 줄거리만 사용한다. 따라서 TMDb의 한국어 줄거리가 존재하더라도 위키백과에 적합한 섹션이 없으면 현재 버전은 원문으로 표시할 수 있다. 한국어 커버리지의 고정 비율이나 완전성을 보장하지 않는다. 원본 영화의 영어가 아닌 실제 제작 언어를 자동 판단하는 기능도 아니다.

## 시네마틱 자동 전환

- **추천 결과 화면에만** 자동 전환을 적용한다. 12초 간격으로 선택된 추천 영화 인덱스를 한 칸 전진시켜 배경·제목·연도·장르·선택 상태를 기존 `renderFilm` 흐름에서 동기화한다.
- 추천 화면의 두 배경 레이어만 2초 `opacity` 크로스페이드한다. 기존 `updateMedia`의 이미지 로드 완료 후 교체 방식을 그대로 이용해 검은 화면을 회피한다.
- 전환 3초 전에 다음 영화 배경을 미리 요청하여 캐시 준비를 시도하고, 실패하면 원래 포스터/배경 폴백을 그대로 사용한다.
- 다음/이전 영화 선택, 화면 재렌더링, 메뉴·검색·상세 모달 닫기 이후에는 12초 타이머를 새로 시작한다. 동시에 하나의 자동 전환 타이머와 하나의 프리로드 타이머만 유지한다.
- 평가 화면, 분석 화면, 내 평가 화면, 메뉴·검색·상세 팝업을 여는 동안, 브라우저 탭이 숨겨진 동안 또는 모션 감소 설정이 활성화된 동안에는 중단한다. 이후 다시 추천 화면을 보고 조작이 끝나면 타이머를 재개한다.
- 평가 화면에서는 영화가 절대 자동으로 바뀌지 않는다. 이 기능은 추천 성능이나 학습데이터와 무관한 UI 애니메이션이다.
