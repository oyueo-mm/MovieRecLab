# MovieRecLab V16 — 전체 영화 보기 및 그리드 즉시 평가

## 문제와 해결 범위

기존 시네마틱 영화 평가 화면은 포스터 레일에 약 4편이 동시에 보이고, 레일은 약 150개 영화로만 빠르게 탐색된다. 전체 MovieLens latest-small 카탈로그에 접근하려면 검색으로 특정 영화를 찾아야 했다. 이 작업은 기존 큰 배경·영화 평가·추천 모델·추천 6개 줄·'내 평가' 메뉴를 유지하고, 빠른 포스터 레일과 전체 영화 그리드를 분리한다.

- **첫 평가 화면의 포스터:** 같은 위치, 같은 큰 배경 디자인을 유지하되 카드 폭과 레일 높이를 조정해 데스크톱에서 대략 5~6편이 보이도록 개선한다. 영화 순서 및 기존 최대 150개 빠른 선택 후보는 변경하지 않는다. `n / 150` 위치 표시를 추가한다. 터치·휠·방향키는 이전과 같다.
- **전체 보기:** 첫 평가 화면 오른쪽 아래에 `전체 보기` 버튼. 실제 `bridge.catalog()`의 **모든** 영화(표준 MovieLens Small 데이터에서는 9,742편)를 읽는 어두운 독립 전체 화면을 연다. 첫 화면 시네마틱 배경은 제거하지 않고 가려 두므로 닫으면 그대로 돌아온다. 검색은 한글 표시 제목, MovieLens 원제 및 제작연도에 대해 수행한다. 검색어가 없다면 미평가 우선/인기순/최신 영화순/제목순으로 정렬한다. 이전 사용자 요청에 따라 장르 필터는 추가하지 않는다.
- **그리드에서 평가:** 각 포스터 아래에 5개의 별을 제공하고 마우스/터치의 왼쪽 반을 누르면 0.5점 단위로 선택한다. 키보드 좌우 방향키로도 현재 평점을 0.5점씩 조정한다. 같은 점수를 다시 누르거나 ×를 누르면 평가를 취소한다. 기존 `bridge.rate/unrate`만 호출하므로 원래 EASE 추천·다른 추천 알고리즘·`내 평가`의 동일한 사용자 프로필을 공유한다. 화면을 닫지 않고 여러 영화를 연속 평가할 수 있고, 3편 이상이면 기존 추천 화면으로 넘어갈 수 있다.
- **선택 기능:** 그리드 포스터를 누르면 그리드를 닫고 해당 영화를 메인 시네마틱 영화 평가 화면에 올린다. 기존 150편에 없던 영화라면 현재 화면의 빠른 선택 레일 맨 앞에 임시 추가한다. 백엔드 데이터는 추가·복제하지 않는다.
- **진행 상태:** 혼동을 주던 `0 / 3편 평가` 문구를 `0편 평가 · 3편 더 필요`로 변경한다. 3편 이후는 `n편 평가 완료`로 표시하며 평가 자체의 상한은 없다.

## 성능 및 접근성

전체 9,742편을 한꺼번에 DOM이나 이미지 요청으로 생성하지 않는다. 처음 48개 카드만 표시하며, 추가 버튼·화면 하단 스크롤·IntersectionObserver를 통해 48개씩 점진적으로 추가한다. 시야에 들어오는 포스터 이미지는 별도의 IntersectionObserver로 지연 바인딩하며, 지원하지 않는 브라우저에서는 각 배치의 앞부분만 바인딩한다. 화면을 닫거나 검색/정렬을 변경할 때 이미지 구독과 관찰자를 해제해 이전 요청을 유지하지 않는다. 완전한 DOM 가상화(이미 생성한 카드를 화면 밖에서 제거하는 방식)는 아니므로 수천 개를 끝없이 스크롤하는 환경에서 추가 최적화가 필요할 수 있다. 검색·정렬은 실제 브라우저 메모리의 카탈로그를 사용하고 API 검색·개인정보 저장은 추가하지 않는다.

모바일 3열(아주 좁은 화면 2열) 반응형. 검색 입력·정렬 선택·카드별 접근성 라벨, 키보드 별점, `Esc` 닫기와 포커스 복귀를 지원한다. 추천 결과 화면에서는 전체 보기 버튼을 숨기고 기존 추천 6개 줄 및 12초 자동 배경 전환은 유지한다.
