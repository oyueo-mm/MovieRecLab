## Important limits
Full native source has ~62k catalog titles; dense exact inverse at that size is not appropriate for standard runners and is not claimed. Full dense EASE targets the entire matched service catalog; SLIM is per-target support-restricted, not unrestricted joint optimum. Full-graph LightGCN uses sampled BPR edges; cold-start inference uses item-based fold-in. MF/SVD++/FM/NeuMF do not use held-out user embeddings; inferred user vector from supplied profile. No raw data or per-user output is published. Time-decay input timestamps are available in MovieLens, not necessarily visitor watch history; deployment cannot assume them. No automatic release gate.
