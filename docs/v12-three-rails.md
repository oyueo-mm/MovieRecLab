# MovieRecLab V12 — 세 가지 테마 추천 줄 (2026-11-12)

## 범위

기존 세 추천 줄(EASE/선택 모델, V6 User KNN, V10/V11 영화 유사도), 기존 연구·평가 UI, 포스터와 한국어 제목은 변경하지 않는다. 추가 추천 모델이 **검증된 모델 자동 선택(auto)** 이고 25M V10 학습 산출물이 준비되었으며 사용자가 영화를 3편 이상 평가했을 때만 다음 세 줄을 뒤에 덧붙인다. **V8·V9·V10·V11 실험 선택 시에는 V12의 세 줄을 아예 표시하지 않는다.** 모델이 없거나 예외가 발생하면 원래 세 줄만 보인다. 매번 실제 추천 결과를 계산하고, 이미 평가했거나 기존 추천 줄·새 추천 줄에 노출된 영화를 다시 추천하지 않는다. 각 새 줄에 추천 가능 영화가 6개 미만이라면 해당 줄을 숨긴다.

## 실제 구현 알고리즘

1. **숨은 명작**: 현재 공개 카탈로그의 실제 평가 수 `n >= 5`, 평균 평점 `avg >= 3.45`를 요구한다. 기존 앱의 MovieLens `ml-latest-small`에서 계산한 평점·건수로 베이지안 보정 평점 `(n·avg+20·3.5)/(n+20)`을 계산한다. 인기 정도는 25M 오프라인 계수의 정규화 로그 빈도로 측정하고, 이 분포의 65백분위수 이하인 작품으로 후보를 제한한다. V10 개인화 순위, 보정 평점, 인기도 역수를 가중 조합해서 재정렬한다. **보정 평균은 25M의 직접 추산치가 아니며 Small 통계의 한계를 가진다.** 평점 3.5, 65백분위수, 가중치는 검증 이전의 휴리스틱 출발값이다.
2. **새로운 취향 발견**: V10 상위 350개 후보 중 Tag Genome 24차원 임베딩이 있고, 기존 4점 이상 평가 영화와의 최대 의미 유사도가 0.04~0.90인 후보를 대상으로 MMR(Maximal Marginal Relevance) 그리디 재정렬을 수행한다. 점수는 `0.72·개인화 관련성−0.28·이미 선정된 영화와의 최대 의미 유사도+0.12·새로움`이다. 기존 세 번째 줄과 달리 인기 우선 재정렬을 사용하지 않는다. 이 추천의 새로움은 실제 이용자의 신규 장르 만족도를 입증하는 값이 아니다.
3. **취향에 맞는 장르**: 각 평가 영화의 장르에 별점 편차 `rating−3`을 반영하고, 다중 장르 영화는 장르 수로 나눠 증거를 중복 가산하지 않는다. 장르 점수는 `sum/(evidence+2)`로 0 prior에 수축시키며, 긍정 평가가 존재하고 점수가 0.08보다 큰 장르만 채택한다. 가장 선호도가 높은 장르의 실제 작품만 V10 관련성과 Tag Genome의 해당 장르 긍정 평가 영화 유사도로 재정렬한다. 증거가 충분하지 않으면 줄을 숨긴다.

## 모델과 데이터의 분리

세 추천 줄 모두 **MovieLens 25M으로 이전에 학습한 V10 영화 유사도**를 재사용하며, **Tag Genome 24차원 도출 벡터**를 사용하는 줄은 새로운 취향 발견과 장르 추천이다. `ml-latest-small`은 사용자 평점, 장르, 영화별 작은 표본의 평균·평가 수를 제공한다. 원본 MovieLens 25M 사용자 평가 행렬이나 원본 Tag Genome은 배포하지 않는다. 25M 영화별 평균 평점을 새로 학습·배포했다고 주장하지 않는다.

## 테스트 및 진실한 해석

- `tests/v12-rails.test.js`: **실제 저장소의 25M 압축 모델을 불러와** 세 줄 추천 12개, 정확한 장르 일치, 추천 내 중복 0건, 기존 추천 줄과의 중복 방지, 3편 미만·모델 미준비 시 폴백, DOM 렌더링, 버전 선택기 존속을 검증한다.
- `tests/v12-quality-live.js`: 고정된 MovieLens Small 공개 원본의 44명 사용자 홀드아웃(5·10편 프로필)에서 V10과 신규 세 줄의 NDCG@10·Recall@10·Hit@10·coverage·내부 의미 유사도를 **같은 진단 조건**으로 측정한다. 세 줄의 적어도 10명 이상 평가, 카탈로그 coverage 10편 이상 및 일치성 기준을 통과해야 한다. 이는 출시 전 실제 데이터에 기반한 진단이지 정확도 상승이나 통계적 유의성이 검증됐다는 의미가 아니다.
- 중요: V10의 압축 계수는 **다른 MovieLens 25M**에서 선행 학습했으며, 새 진단은 Small 사용자에 대한 별도 홀드아웃이다. 이전에 훈련된 25M 모델에 Small 사용자의 과거 기록이 절대로 노출되지 않았음을 엄밀히 입증하는 재학습 실험은 아니다. 따라서 완전 독립적인 25M 평가로 표현하지 않는다. Tag Genome 역시 상위에서 사전 계산된 데이터다.
- 본 세 테마의 목적은 각각 **롱테일 노출**, **추천 내 다양성**, **장르 적합성**이다. 기본 EASE 또는 V11보다 NDCG가 높다고 주장하거나 품질이 검증된 새 협업 필터 모델로 표시하지 않는다. 고정 계수와 검증 지표는 후속 독립 실험에서 조정 가능하다.
