# MovieRecLab V17 — 별점 드래그 입력 (기존 클릭 방식 유지)

## UX

기존 버튼 클릭·별의 왼쪽 반 클릭(0.5점)·키보드 좌우 화살표·평점 취소 기능을 **삭제하지 않고 그대로 유지**한다. 여기에 5개 별을 하나의 수평 입력 영역처럼 누른 채 좌우로 드래그하는 방식을 추가한다. 시작 지점에서 4px 이상 움직일 때만 드래그로 간주한다. 드래그 중에는 0.5점 간격으로 별 채움과 점수가 실시간 미리 표시되지만, 기존 추천 엔진/평점 저장은 변하지 않는다. 버튼에서 손가락·마우스를 떼면 최종 점수를 **한 번만** 저장한다. 동일한 평점을 그대로 두고 드래그를 종료하면 평가를 취소하지 않는다(반면 기존 동일 별 재클릭=평가 취소는 유지). 손가락 조작 취소, pointercancel, 창 포커스 상실 시에는 이전 값으로 되돌린다. 마우스뿐 아니라 표준 Pointer Events를 제공하는 터치 기기와 펜을 지원한다.

## 적용 범위

- 첫 영화 평가 화면: 기존 큰 별점 5개를 그대로 드래그 가능하게, 실시간 수치 미리보기
- 전체 9,742편 영화 목록: 각 그리드 카드별 별점 5개를 그대로 드래그 가능하게, 카드 미리보기 및 기존 `bridge.rate/unrate` 사용
- 영화 상세 시네마틱 팝업: `내 평점` 5개 별점 드래그, 0.5점 미리보기 및 직접 저장
- `내 평가` 화면: 별점 조작을 위해 기존 포스터 버튼 아래에 작고 독립적인 별점 행을 추가; 기존 포스터 터치로 상세 열기와 별점 클릭·평가 취소 및 정렬을 유지

## 동작 보호

- 기존 일반 `click` 이벤트는 손대지 않고, `pointerdown`에서 윈도우 단위로 드래그 움직임을 관찰한다. 실제 드래그(4px 이상 수평 이동)가 일어난 직후 자동 생성된 `click`만 제거하여 이중 평가와 동일 별점 취소를 방지한다. 단순 탭은 기존 클릭으로 전달한다.
- 전체 별 영역은 `touch-action:none`으로 직접 드래그할 수 있다. 세로 스크롤은 별 영역 밖의 카드/목록에서 정상 동작한다.
- JS/스타일은 별도 `showcase/rating-drag.js`/`.css`로 유지해 기존 ML25M 추천 모델, 6개 추천 줄, 한국어 줄거리, 12초 영화 자동 전환을 수정하지 않는다.
- `내 평가` 별점 수정 시 결과를 다시 불러와 카드 정렬과 상세 정보를 동기화한다. 동일한 사용자 평점 저장소를 계속 이용하며 신규 계정·서버 저장은 도입하지 않는다.

## 테스트

`tests/v17-rating-drag.test.js`는 실제 Showcase DOM과 mock MovieRecBridge를 사용하여 네 화면에서 드래그 중 점수 미리보기, 손을 떼는 순간 한 번만 저장, 터치 취소 시 원복, 드래그로 인한 후속 클릭 억제, 기존 일반 클릭 및 키보드, 상세의 평가 취소, `내 평가` 업데이트까지 검증한다. 기존 V16의 전체 영화 9,742편·포스터 지연 로딩, V15.1 한국어 줄거리, V14 시네마틱 상세 UI, V9~V12 추천 품질 및 V13 프리셋 회귀 테스트도 함께 실행한다.
