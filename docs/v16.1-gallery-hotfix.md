# MovieRecLab V16.1 — 전체 영화 포스터·상단 정렬 긴급 수정

## 원인

V16 전체 영화 화면은 최초 48장의 카드를 화면에 만든 후 `IntersectionObserver`를 생성했지만, 초기 48장을 포스터 로딩 관찰자에 등록하지 않았다. 원래 즉시 로딩하던 앞 12편을 제외한 초기 36편은 나중에 스크롤해도 이미지 바인딩이 시작되지 않아 포스터가 비어 보일 수 있었다. 다음 배치 48편부터는 생성 시 관찰자로 등록했기 때문에 정상적으로 로딩되는 불규칙한 현상이 생겼다.

또한 검색창과 정렬 항목의 스크린리더 전용 레이블에 사용한 `.sr-only` CSS가 전체 영화 화면에 정의되지 않아 `영화 제목 검색`, `전체 영화 정렬` 등이 눈에 보이는 텍스트로 배치되었다. 헤더의 기존 flex 레이아웃에서는 텍스트가 입력창과 정렬 옵션 사이에 끼어 줄바꿈과 정렬 어긋남이 발생했다.

## 수정

- 초기 48편도 `IntersectionObserver`에 등록한다. 앞 12편은 빠른 첫 표시를 위해 기존처럼 즉시 포스터 로딩을 시작하고, 나머지는 실제 보일 때 로딩한다. 이후 추가 로딩되는 48편도 기존처럼 관찰한다.
- 검색어·정렬 변경 및 화면 닫기 시 기존 포스터 관찰자와 이미지 구독을 해제한다. 로딩 실패한 원본에 대해서는 기존의 포스터 후보 재시도와 영화 제목 폴백을 유지한다.
- `.sr-only`를 실제 시각적 숨김 속성으로 처리하되 보조 기술에서는 접근 가능하게 유지한다.
- PC 상단은 뒤로 가기 / 제목·영화 수 / 검색 / 정렬의 4열 정렬, 좁은 화면에서는 뒤로 가기·제목·정렬의 첫 줄과 전체 너비 검색의 둘째 줄로 배치한다.
- `all-films.js`/`all-films.css` 캐시 버전을 `v=161`로 변경한다. 기존 시네마틱 홈, 추천 알고리즘, 0.5점 평가, 내 평가, 12초 자동 전환 및 한국어 영화 줄거리는 수정하지 않는다.
