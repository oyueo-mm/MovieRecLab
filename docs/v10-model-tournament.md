# MovieRecLab V10 — 공통 평가환경 추천 모델 토너먼트

## 목표와 변경 범위

V10은 V9의 문제점이었던 **서로 다른 데이터·분할에서 측정한 추천 점수를 직접 비교하는 오류**를 해결하기 위한 버전이다. UI의 시네마틱 히어로, 평점 입력, 기존 3개 추천 줄, 영화 포스터, 번역, 검색, 기존 EASE·추천 도감·연구 화면은 유지한다.

변경 항목은 새로운 **오프라인 대규모 학습·평가 파이프라인**과 테스트를 통과한 영화 유사도 모델을 선택적으로 붙이는 브라우저 추론 계층뿐이다. 첫 번째 기본 EASE 추천 줄은 기존 모델을 그대로 사용한다. 두 번째 사용자 추천 줄도 데이터가 부족하거나 실제 유사 사용자 기반 개선이 검증되지 않았으면 기존 V8 User KNN을 그대로 사용한다.

세 번째 영화 유사도 줄은 V10 최고 후보가 실제 홀드아웃 평가에서 기존 V9 Tag Genome 모델을 **입력 5편과 10편 모두에서** 이긴 경우에만 V10을 우선 채택한다. 그렇지 않으면 기존 V9가 유지된다.

메뉴의 추가 추천 모델에서는 **검증된 모델 자동 선택 / 25M Tag Genome(V9) / 기존 추천(V8) / 25M 전체 실험(V9) / V10 우승 모델 비교** 중 선택할 수 있다. 데이터는 브라우저를 벗어나지 않으며 영화 평점을 다시 입력할 필요가 없다.

## 25M 오프라인 모델 공정 비교

[재현 가능한 코드](../scripts/benchmark_v10.py)에서 25M 원본 ZIP은 **임시 CI 작업 환경에서만** 처리한다. 현재 앱의 MovieLens latest-small 영화 ID에 IMDb·TMDb ID 양쪽이 정확히 일치하는 영화만 사용한다.

- 전체 평점 25,000,095건에서 약 320명을 **모든 학습에서 제외**한다. 제외 사용자를 서로 겹치지 않는 검증 집합 및 최종 테스트 집합으로 분할한다.
- 각 사용자에서 가장 오래된 평점 5편·10편을 프로필로 주고, 최근 20%의 평점 4점 이상 영화를 정답으로 삼는다.
- 모델마다 같은 약 9,448편의 영화 후보 목록을 사용하고, 이미 평가한 영화는 제외한다. EASE는 계산 비용을 고려하여 **인기 1,200편 하위집합에만 학습**한다. 나머지 영화의 점수는 매우 낮게 처리한다. 따라서 EASE 실험은 전체 카탈로그 EASE 모델과 동등하지 않다.
- 비교 알고리즘: 25M 인기도, V9 Tag Genome, 25M 협업 SVD, User KNN, Item KNN, 인기 1,200편 EASE, Implicit ALS, BPR, Item2Vec 및 Tag Genome+ALS·Item KNN·Item2Vec 하이브리드.
- 임베딩 기반 모델은 신규 방문자 프로필의 선호 가중합으로 점수를 추론한다. ALS/BPR의 기존 학습 사용자 요인을 신규 방문자에게 그대로 사용하지 않는다. BPR의 경우 **학습된 아이템 임베딩으로 신규 방문자를 점수화**하는 비교이며, 원래 학습 사용자에 대한 BPR 예측과 동일한 것은 아니다.
- 지표: NDCG@10, Recall@10, HitRate@10, Coverage. **검증 사용자만으로 우승 모델을 선정한 뒤**, 완전히 구분된 테스트 사용자에서 V9 모델보다 NDCG가 입력 5편·10편 모두 높아야 한다.
- User KNN은 동일 데이터에서 실험하지만 개별 25M 사용자 평가 행렬 또는 유사 이웃 프로필을 공개 사이트에 배포하지 않는다. 따라서 실제로 검증되고 안전한 사용자 추천 기능을 구현할 수 없는 경우에는 V8 KNN을 대체하지 않는다.

[공개 평가 결과](../showcase/v10-benchmark.json)에는 모델별 지표, 검증·테스트 사용자 수, 선정된 알고리즘과 두 추천 줄의 채택 여부를 기록한다. **우승 모델이 검증에서만 좋거나 최종 테스트에서 실패하면 신규 모델은 자동 활성화하지 않는다.**

## 실제 25M 평가 결과 (2026-11-12)

[검증된 모델별 JSON 지표](../showcase/v10-benchmark.json)에서 NDCG@10·Recall@10·HitRate@10·Coverage를 모두 확인할 수 있다. 모델 12종, 약 9,448개 동일 ID 매핑 영화, **검증 사용자 157명 + 테스트 사용자 156명**. 독립 검증으로 고른 모델은 **Tag Genome + Item KNN**이다.

| 모델 (독립 테스트) | 입력 5편 NDCG@10 | 입력 10편 NDCG@10 | 적용 |
| --- | ---: | ---: | --- |
| 인기도 기반 | 0.045159 | 0.046490 | 비교 기준 |
| 기존 V9 Tag Genome | 0.031567 | 0.050537 | V9 폴백 |
| Item KNN | 0.029414 | 0.040723 | 실험 |
| User KNN | 0.029622 | 0.043790 | 인기도 기준선 미달, 미채택 |
| EASE (인기 1,200편만) | 0.035105 | 0.042481 | 제한 범위 비교 |
| ALS | 0.022967 | 0.031323 | 실험 |
| BPR 잠재 요인 | 0.020609 | 0.031019 | 실험 |
| Item2Vec | 0.020241 | 0.024907 | 실험 |
| Tag Genome + Item KNN | **0.032837** | **0.051123** | **V10 기본 추천(영화 유사도 줄만)** |

V10 우승 모델은 V9와 비교하여 NDCG@10이 입력 5편에서는 약 4.0%, 입력 10편에서는 약 1.2% 상승했다. **미세한 효과로서 통계적 유의성이 입증되지 않았으며 온라인 만족도 개선을 보장하지 않는다.** 실제 이용 환경에서 성능이 나쁘면 메뉴에서 즉시 V9 또는 V8로 복구할 수 있다.

학습 당시 희소 공동 평가 행렬은 정확히 25M 다운로드 후 계산되며, 브라우저에는 **영화별 상위 75개 이웃을 16비트 ID 인덱스와 16비트 가중치로 무손실 압축**한 도출 모델만 배포한다. 원본 약 8.3MB의 텍스트 그래프를 약 **3.83MB**로 축소했으며, 계산된 추천 순위에 영향을 주지 않는다.

이 결과는 **기존 V8 User KNN과 동일 데이터에서 직접 비교한 결과가 아니다**. V8 User KNN은 사용자의 취향에 근거한 추천으로 계속 유지한다.

## 학습 결과와 배포

- 학습 코드는 [scripts/benchmark_v10.py](../scripts/benchmark_v10.py); 실행은 [GitHub Actions V10](../.github/workflows/train-v10.yml)이다.
- 원본 평점, Tag Genome 원본, 학습 사용자별 평가 내역, 개인별 사용자 임베딩은 GitHub에 게시하지 않는다.
- 영화별 압축 모델 산출물 [showcase/v10-model.js](../showcase/v10-model.js)만 배포하며, 10MiB를 넘지 않게 제한한다. 모델이 채택되지 않았다면 파일에는 **채택 실패 정보만** 들어 있다.
- [showcase/v10-recommender.js](../showcase/v10-recommender.js)에서 모델이 없거나 최소 평점 개수가 부족하면 V9 또는 V8로 자동 복구한다.
- 브라우저에서 모델·파라미터 선택과 평가 재실행은 사용자 관여 없이 서버로 데이터를 보내지 않는다.
- 오프라인 측정값은 온라인 사용자 만족도나 통계적 유의성을 보장하지 않는다. MovieLens 데이터와 실제 서비스 이용자 간 분포 차이가 있다.
- [MovieLens 25M 이용 조건](https://files.grouplens.org/datasets/movielens/ml-25m-README.html) 및 [GroupLens 안내](https://grouplens.org/datasets/movielens/). 원본 데이터 재배포에는 제한이 있으므로 원본 파일을 커밋하지 않는다. 가공 계수의 2차 사용은 목적과 라이선스를 별도 검토한다.
