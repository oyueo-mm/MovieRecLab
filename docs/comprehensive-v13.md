# Comprehensive V13 research (offline only)

No production deployment or changes to main. All raw data remains transient on hosted runners. Only aggregate JSON results are exported.

## Prespecified
A: first n vs latest 20%; B: random n from earlier 80% vs same latest 20%; C: first n vs random 20% of remaining records (target count based on whole history); D: random n from all records vs random target from remainder. B-D five repeats; A once. Equal four-protocol NDCG@10 objective, deterministic user splits. 25M fresh user remainder 43 mod 509, even/odd validation/test. Small fresh 160 excluding known 44/88/160 cohorts, native model comparison descriptive; adaptive validation and test 80/80.

Full-size 25M: 24 input counts (3-20,25,30,40,50,75,100); Small and scale runs six representative counts (3,5,10,20,50,100). 25M source mapped to current ~9.4k title catalog. Sample nested whole training users to target 100k,500k,1m,5m,10m positive interactions; full training retains all available positive mapped interactions. NOT 25M explicit training ratings. Common full-size candidate eligibility and same held-out profiles for scale comparison. Small vs 25M native users are not directly matched; do not compare their absolute numbers as size effects.

25M expands existing tournament with genre, tag-only, implicit NMF, approximate limited SLIM, association confidence, 3000-film EASE, neighbor shrinkage, negative rating and recency-order sensitivity, popularity mixing and genre hybrid. Some expensive candidates can fail; failures logged. Candidate selection uses validation only: shortlist five single policies, RRF/Borda pair weights .25/.5/.75, RRF constants 20/60, equal top-three. Choose ensemble only if validation improvement >= .001. Test reports selected candidate and fixed comparator models, paired exploratory bootstrap CI vs frozen V11. No automatic acceptance or release. Metrics: NDCG, Recall, Precision, Hit, MRR, genre diversity, novelty, coverage at 5/10/20/50. Profile positivity strata; aggregate inference timing and peak memory. Small reports @10 and tests prior RRF families.

## Explicit limits
This is first comprehensive execution, not every possible combination. 25M uses binary positive matrix, no full explicit MF/SVD++/FM/NCF/LightGCN/LightFM/stacking/LDA/Word2Vec distinct from Item2Vec yet. Model scope and candidate restrictions differ. No fitted model export or browser latency benchmark in this phase. Whole-service multi-rail diversity, feature timestamp leakage, true calendar-time decay, exact hyperparameter retraining and significance multiplicity adjustment remain to be addressed. Results should be treated as exploratory; no claims based on failed/skipped jobs. A-D not fully factorial because B samples only old records while D samples all. Partial artifacts may exist after failure; check job status and completed count.
