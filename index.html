오프라인 추천 성능 평가

평점 데이터를 시간순으로 나누고 같은 조건에서 기존 알고리즘과 선택한 고급 알고리즘을 평가합니다.

평가는 자동 실행되지 않습니다. 시작 버튼을 눌러주세요.
평가 설계 및 한계평가 대상으로 선택한 사용자 전체를 학습 데이터에서 제외한 뒤, 그 사용자의 초기 K개 평점을 입력받아 시간순 마지막 20%에 포함된 4점 이상 영화를 추천하는지 확인합니다. 전체 카탈로그를 대상으로 Recall@10·NDCG@10·Hit Rate@10·Coverage를 측정합니다. 평가하지 않은 영화는 선호 여부를 알 수 없으므로 실제 만족도와 동일하지 않습니다. 테스트 데이터로 하이퍼파라미터를 반복 조정하면 과적합될 수 있어 최종 평가에서는 별도의 검증 집합이 필요합니다.

인기 기반

평점 평균을 전체 평균으로 수축하는 베이지안 평활화로 평가 횟수가 적은 영화의 극단적인 점수를 보정합니다. 개인화하지 않는 기준선입니다.

콘텐츠 기반 (장르 + 태그)

영화 장르 IDF·태그 겹침으로 콘텐츠 유사도를 계산하고 입력 평점과 결합합니다. 태그가 있는 영화만 태그 정보를 활용하므로 장르가 중심입니다.

사용자 기반 KNN

평가한 영화의 3점 대비 선호 신호와 다른 사용자의 평균 중심화 평점을 비교합니다. 공통 평점 개수가 적으면 유사도를 축소하고 비슷한 사용자의 다른 평점으로 추천합니다.

아이템 기반 KNN

같은 사용자가 평가한 영화 쌍에서 사용자 평균을 뺀 평점으로 조정 코사인 유사도를 계산합니다. 공통 평가가 적으면 가중치를 줄여 추천 안정성을 높입니다.

하이브리드

함께 높게 평가된 영화의 연관성, 인기·평점 점수, 유사 사용자 추천 순위를 가중 결합합니다. 처음 5편을 평가하는 상황에서 실험한 방식이며, 성능은 평가 표본에 따라 달라질 수 있습니다.

성능 평가

시간순 데이터 분리, 평가 사용자 학습 제외, 동일한 후보 집합을 통해 정보 누출을 줄였습니다. 관측되지 않은 영화는 실제 비선호가 아니므로 결과는 오프라인 근사치입니다.
